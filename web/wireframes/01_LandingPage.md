### Layout General

```
+-------------------------------------------------+
| [Header]                                        |
|  - Logo                                         |
|  - Navegación (Features, Pricing)               |
|  - Botones (Login, Register)                    |
+-------------------------------------------------+
| [Sección Hero]                                  |
|  - Título Principal                             |
|  - Subtítulo                                    |
|  - Botón de Llamada a la Acción (CTA)           |
|  - Imagen o ilustración                         |
+-------------------------------------------------+
| [Sección "Cómo Funciona"]                       |
|  - Título de la sección                         |
|  - Pasos (ej. 1. Busca, 2. Reserva, 3. Califica)|
+-------------------------------------------------+
| [Sección de Testimonios]                        |
|  - Título de la sección                         |
|  - Carrusel de tarjetas de testimonios          |
+-------------------------------------------------+
| [Sección de Precios]                            |
|  - Título de la sección                         |
|  - Tabla o tarjetas comparando planes (Premium) |
+-------------------------------------------------+
| [Footer]                                        |
|  - Enlaces                                      |
|  - Redes Sociales                               |
|  - Copyright                                    |
+-------------------------------------------------+
```
